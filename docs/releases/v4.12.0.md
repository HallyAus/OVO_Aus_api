# OVO Energy Australia v4.12.0

Released 5 November 2026 (Australia/Sydney). This feature release includes Joshua Rutland's contribution in #98, landed on main through #101, together with the README support referrals in #99 and the Dependabot auto-merge workflow in #100.

## Options and billing

- The options screen now starts with device grouping and a manual-plan switch. Billing-cycle day, peak hours and tariff overrides stay on the manual step.
- The billing cycle start day is read from the latest statement `periodFrom` while `billing_cycle_day` is absent from options. Saving that day on the manual step pins it, and auto-detect stays off until the key is no longer stored. A normal save of the first options screen does not write a fallback day, so it does not pin the cycle.
- If auto-detect moves the cycle, the bill estimate is rebuilt for the new bounds.
- An installation that already saved a plan, before `manual_override` existed, keeps that plan: the manual switch defaults on so submitting options does not clear it.

## Entities

- EV charging and EV off-peak sensors are created only when the account has an EV plan, a connected vehicle, or usage that already includes an EV rate. EV entities already in the registry are removed for other accounts. Vehicle access remains read-only.
- Billing-period labels now say Billing Month to Date and Last Billing Month. Sensor keys and unique IDs are unchanged, so existing entity history stays with those entities.
- With single-device consolidation enabled, the category is appended to names that would otherwise collide. Consolidation remains off by default.
- Stale secondary devices can be removed. The live account device cannot, and empty category devices are removed when consolidation is on.

## Documentation and maintenance

- The README now opens with Support referrals for Tesla, OVO Energy and Starlink (#99).
- Dependabot pull requests in this repository enable squash auto-merge. Required checks on `main` still have to pass before GitHub merges (#100).
- `actions/checkout` is pinned to v7.0.1 (#95). `softprops/action-gh-release` is pinned to v3.0.3 (#94).

## Upgrade

Update through HACS and restart Home Assistant. Existing entity unique IDs are preserved. Accounts without EV usage lose the EV-only entities. A previously saved manual plan is kept unless manual override is turned off.

OVO usage totals remain delayed provider data. An auto-detected billing day follows the latest statement and does not reconstruct a bill by itself.
