## A smaller, more useful entity set

- The account surface is reduced from 281 to 105 entities. An enrolled vehicle
  adds 19 entities on its own linked device, for 124 total with one vehicle.
- Removed 140 moving Day 1-7 entities and 21 moving hourly-day entities.
- Upgrade cleanup removes those retired entries from Home Assistant's entity
  registry instead of leaving 161 unavailable entities behind.
- Stable period totals, Yesterday Hourly attributes, the seven-day heatmap, and
  Home Assistant Energy Dashboard entities remain available.

## Consolidated information

- Six standalone tariff-rate entities now live as attributes on Plan Information.
  Current Tariff Period remains a normal entity.
- Daily, monthly, and yearly OVO savings now live on one Plan Savings entity.
- Latest bill amount, opening balance, and closing balance now live on Latest Bill.
- The incomplete Monthly Forecast is removed. Bill Estimate is now the only
  forecast and includes standing charges and export credits.

## Corrected solar and cost analytics

- High Usage Days now measures household use as grid import plus self-consumed
  solar, so exported solar no longer makes sunny days look like heavy-use days.
- Week comparisons and weekday/weekend figures use grid charges less export
  credits and explicitly identify that supply charges are excluded.
- Net Usage Cost per kWh uses household consumption; the former Solar Cost per
  kWh entity now reports the useful export-credit rate.

## Honest data freshness

OVO meter usage normally arrives the following morning and is not real-time.
Integration Health now reports the newest usage date, delay in days, expected
one-day delay, and a stale warning when usage is more than two calendar days old.
Connected-vehicle telemetry remains separate and may be newer than meter data.

## Dashboards and automations

Bundled dashboards now use Plan Savings and Bill Estimate. The Daily Savings
Report blueprint reads daily and monthly savings from Plan Savings attributes.

### Upgrade note

Existing dashboards and automations that reference removed Day 1-7, hourly-day,
standalone savings, standalone tariff, standalone bill-value, or Monthly Forecast
entities must be updated to use the consolidated entities and attributes above.
