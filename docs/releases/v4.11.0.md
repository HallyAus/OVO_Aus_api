# OVO Energy Australia v4.11.0

Released 2 November 2026. This release includes rutj87's contribution in #92, together with the runtime corrections and security cleanup in #93.

## New features

- Numeric current electricity price and solar feed-in tariff sensors, expressed in AUD/kWh.
- A dedicated free electricity window binary sensor for automations: Free 3 from 11:00 inclusive to 14:00 exclusive; Free 4 from 11:00 inclusive to 15:00 exclusive.
- Optional single-device consolidation. It is disabled by default, preserving the existing category grouping.

## Tariff fixes

- The free-window entity uses Home Assistant's binary sensor state handling and publishes on/off rather than unknown.
- The free window, current price and tariff period update at local tariff boundaries without waiting for the five-minute API poll. Normal Home Assistant scheduler latency still applies.
- Live tariff windows follow Home Assistant's configured timezone, including Sydney daylight saving, with regression coverage for Adelaide and Brisbane.
- A zero ordinary rate does not falsely activate the free-window sensor. Remaining hours include minutes and seconds; the value is a snapshot, not a continuously ticking countdown.

## Security and reliability

- Prevent credentials and authentication tickets from being forwarded to unintended destinations through redirects.
- Redact legacy OAuth tokens in diagnostics and retire obsolete token fields after successful reauthentication.
- Validate complete token responses before updating credential caches, and keep sensitive provider details out of errors and tracebacks.
- Report malformed vehicle responses as communication failures instead of misleading empty results. Vehicle access remains read-only.
- Strengthen source, secret, dependency and release-integrity checks; require all seven named CI gates to pass for the exact main-branch source being released.
- Pin workflow actions and validator images, verify release tag provenance, and package only validated integration files.

## Upgrade and scope

Update through HACS and restart Home Assistant. Existing entity unique IDs are preserved; the new consolidation setting is opt-in. For a Sydney property, Home Assistant should be configured to Australia/Sydney.

OVO usage totals remain delayed provider data. A live price sensor does not backdate delayed meter readings or guarantee exact bill reconstruction in the Energy Dashboard.

**This release installs only the OVO integration.** The separately labelled Home Assistant/Pillow security backport is a test environment, is not included in the integration ZIP, and does not patch Home Assistant core on users' systems. Keep Home Assistant itself updated separately.
